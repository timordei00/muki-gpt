# Design and user experience

Identify what the visitor needs to recognize, compare, trust or do. Collect the real names, copy, imagery, assets and editorial constraints that support that action. For an existing site, inspect its components, voice and recognizable elements. Ask the client when a promised fact, contact, credential or right to publish has no owner.

For a new direction, name a brand trait and the evidence behind it. Sketch the information order using actual material. Choose a composition, type hierarchy, spacing rhythm, color roles, imagery and primary action that express that trait. A useful rationale names something visible and what it lets this audience do. Compare another direction only when it would change a meaningful decision. Let the amount and shape of the content determine the number of sections.

- Give each page one intelligible purpose, descriptive navigation and a clear next step. Use the visitor’s words. Ensure a link’s destination and an action’s outcome match its label.
- Design the complete interaction where applicable. Include waiting, partial content, empty, validation, success, unknown outcome, retry and back. Preserve editable input and show how to recover. Agree the meaning of the success message with the system that performs the work.
- Use motion to explain continuity, hierarchy or a state change. Keep the content and action available on touch, keyboard and with reduced motion. Give media an intentional crop or alternative. Choose a functional fallback font.
- Inspect a real render with representative text and assets. Check first impression, hierarchy, legibility and the primary task at narrow and wide sizes. Record provisional assets, usage rights, credits and who approves them. Use visible preview labels for illustrative claims or actions.
