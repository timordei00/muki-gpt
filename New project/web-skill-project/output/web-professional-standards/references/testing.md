# Select a discriminating check

Write the invariant and an observation that could contradict it. Select the cheapest layer with authority to answer it. Choose an expected failure and a valid alternative when a simple signal may produce false confidence.

| Layer | Procedure | Boundary |
|---|---|---|
| Source/build | Inspect the actual built document, route-specific heading, meaningful link target, language, title and relevant assets. Compare to an agreed contract. | Can establish facts about the artifact. Dynamic states and hosting may differ. |
| Controlled browser | Identify the expected page and control first. Drive the real keyboard or pointer task at the failing width and between transitions. Inspect open, loading, reduced-motion and error states as appropriate. Observe runtime errors and actual resource responses. | Page-width checks can miss overlap and obscured focus. Missing equipment or a wrong page leaves dependent checks NOT TESTED. A required control absent on the identified page is a FAIL. |
| Manual task | Use representative content, real focus order, zoom, assistive technology or device. For visual quality name what the person needs to recognize and record what happened in the render. | A screenshot alone cannot establish interaction, semantics or the validity of a business claim. |
| Authorized integration | Agree the disposable target, synthetic data, permission and cleanup. Compare view, accepted request, authoritative record and delivery for distinct expected states. | A simulated response covers the UI only. Without the approved target, leave the integration NOT TESTED. |
| Published environment | Compare deployed route, headers, cache, field metrics or restoration with the project contract. Record build and observation window. | Local inspection cannot confirm production configuration, field performance or recovery. |

Record tool/version or human method, build, route/state, criterion, observation, environment and a non-sensitive evidence reference. Preserve completed checks when another tool is unavailable. For manual handoff bind evidence to the exact build, route and criterion. Keep screenshots, logs and synthetic account details in an approved location. Targeted observation is sufficient for a local fix.
