# Interface and public content · known failure mechanisms

Read after the project-derived risk note. Select a matching trigger. Append newly identified mechanisms as CATALOG and retain the origin of earlier findings. Severity follows the impact on this project.

## UI-INTRINSIC

Long localized text or media enters a narrower component. A track or child keeps its intrinsic minimum and the action moves offscreen (R0 if it becomes unreachable). Allow the responsible item to shrink or wrap. Keep necessary two-dimensional material in an operable local region. Check long and ordinary content at the failing width.

## UI-ORDER

A layout pairs captions, prices or choices by visual placement. Reflow or a missing item changes which label appears to belong to which object (R1, potentially R0 for a wrong transaction). Bind each label to its object in the content and reading order. An intentionally separate key can work if associations remain explicit. Inspect linearized and narrow layouts.

## UI-FOCUS

A responsive disclosure or sticky layer changes what is visible while keyboard focus continues elsewhere (R0 on the only route to the task). Define open, close and focus behavior for the chosen interaction. A simple disclosure need not trap focus. Use only a keyboard, expand, follow a link or dismiss, and locate focus at increased text size.

## UI-MOTION

Essential content or state is revealed only after an animation, observer or hover event (R0 when there is no usable alternative). Render the end state accessibly first. Add the cue where it helps orientation. Decorative-only effects can disappear. Complete the task with reduced motion, touch and the enhancement unavailable.

## UI-MEDIA

A prominent image or font arrives late, displaces the action or hides key detail in a new crop (R1, or R0 when it changes a selection). Reserve space, retain legible fallback and expose the critical resource early. Below-fold imagery can still be deferred. Inspect the actual crop and action during loading on relevant layouts.

## UI-CLAIM

A draft contact, stock portrait, accreditation or review is presented as authentic (severity follows harm, R0 for a critical false claim). Record the source or remove the claim from the release scope. A clearly labeled concept can stay in a preview. Match the rendered material to approved facts, permissions and required credits.

## UI-ROUTE

A shared title, shell or HTTP success response makes an error route look like the intended page (R1, higher if an essential route is lost). Give tests an independent page identity and verify the destination content. A deliberate fallback has its own expected status. Check an expected route, a moved URL and an unknown one.
