# Context index · authoring copy

Use after the project's own pre-code pass. Look up the surface that could change a decision. If the task has no matching dependency, leave the catalog closed.

| Observed project condition | Relevant IDs |
|---|---|
| One component changes width, reading order or language | UI-INTRINSIC, UI-ORDER |
| Disclosure, overlay or an interaction conveyed by motion | UI-FOCUS, UI-MOTION |
| Media-led identity or client-supplied publication material | UI-MEDIA, UI-CLAIM |
| Public URL change, fallback shell or cached older release | UI-ROUTE, SV-RELEASE |
| One intent may be repeated or two actors share capacity | SV-REPLAY, SV-CONTENTION |
| Business confirmation crosses an asynchronous provider | SV-SIGNAL, SV-OWNER |
| Access scope, editor data or untrusted assets change | SV-AUDIENCE, SV-INPUT |
| Different people maintain the published content and its delivery | SV-OWNER, SV-RELEASE |

P3 maps interface and service groups directly to their own small files. Keep these IDs stable for future comparisons. I-A and I-B are exposed illustrations. Missing client-specific retention policy, actual mailbox delivery, production cache behavior and genuinely independent predictions remain open for the respective operator or later evaluator. Their absence cannot turn into a passing test.
